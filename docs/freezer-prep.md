# 每週兩次熟製冷凍備餐

[每週清單](../prep/README.md) · [每日菜單](../plans/README.md)

## 日期與清單怎麼用

預設**週日晚上備週一～三、週三晚上備週四～日**。週末可以備食物，但仍不安排週末首次試新。首週從10/30開始，故另列10/29起始批；末週只備到5/21，不多做規劃外的餐點。

每批列食材採買項目、處理方式、使用日期／餐次、一般與試味用途的次數、分裝估量、可抄寫標籤及庫存空格。先查logs與現有庫存；漏試、出現反應或順延時，先調整每日菜單並重產清單。沒有記錄不能因日期過了就當作已耐受。待後續的40項不列入本期採買。

每週頁面會隨菜單重產；請用 [庫存紀錄範本](../templates/freezer-inventory.md) 複製到logs保存唯一的實際製作、入庫與取用紀錄，以免重跑覆蓋勾選欄。

## 分裝：一樣一格，取用才配成兩樣

- 每種食材單獨熟製、分裝與貼標，不預先混成三樣以上的粥。單一食材只加水調稠，不加未列出的奶、高湯、油或其他配料。
- 一般使用先以**每次食材10mL一小格**估量；試味／觀察候選先以**5mL一小格**估量。例：一批同一蔬菜一般使用4次，可先做4格×10mL＝40mL；若其中2次是試味、2次是一般用途，則約需2格×5mL＋2格×10mL＝30mL。
- **小格是容器與起始備餐量，不是一次餵食量、最低必吃量或過敏原引入劑量。** 新食材可只取格中很少量；剩餘已解凍食物不能重新冷凍。首次過敏原依個別建議，醬類不按5或10mL計劑量。
- 每餐兩樣一般10mL格，合計20mL，僅方便起始備餐。已吃得較多時，按最近實吃量放大製作量，續添同餐兩樣；不要把20mL當作七至十一月齡的全餐目標。未滿六個月的提前試吃量仍須兒科確認。
- 成品體積不等於原料重量；稠度與削皮去骨損耗不同，不能將40mL誤寫為生肉40g。初次依小量製作並量出成品，下次再用實際得率調整採買。

## 不放進同一批冷凍的項目

| 食物 | 本表做法 |
| --- | --- |
| 含鐵嬰兒燕麥 | 依包裝每餐現調；不把數天份先調成糊存放。 |
| 無糖全脂優格 | 維持冷藏並依開封標示取用；用乾淨湯匙舀出當餐量。 |
| 花生／芝麻／杏仁醬 | 原產品按標示保存，食用當餐才取少量以水充分稀釋、拌入同餐另一食物；不是整匙餵，也不預先調一週。 |
| 蛋 | 當日充分煮熟，保留全蛋形式但依能力壓碎；本表不安排硬煮蛋冷凍。 |
| 酪梨、香蕉 | 為品質與減少褐變，預設當餐去皮去核壓泥；並非所有水果都不能冷凍。其他列入冷凍的水果按菜單方式煮軟或處理。 |

硬煮蛋不適合冷凍的資料見[FoodSafety.gov保存表](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts)。以上現調／現做項目仍有採買與日期清單，不是漏備。

## 冷卻、保存與標籤

生熟器具分開，接觸過敏原後徹底清洗；不要把未標示的混合物當單一食材。煮熟後小份快速冷卻，通常1～2小時內入冷藏或冷凍；**米飯與粥類一小時內冷卻並入庫**，不在室溫放整晚。冷藏米飯24小時內用完。[NHS：保存與復熱](https://www.nhs.uk/best-start-in-life/baby/weaning/safe-weaning/storing-and-reheating-food/)

冷藏維持4°C以下、冷凍−18°C以下；不是把一般冷藏保鮮盒放三四天來代替冷凍。[FoodSafety.gov：保存溫度](https://www.foodsafety.gov/food-safety-charts/cold-food-storage-charts)

本表以一批接著三四天使用為主，**家庭冷凍目標28天內用完**，是保守的家庭管理期限；FDA自製嬰兒食品表列冷凍1～2個月，不能把期限視為保存不當也安全。實際製作、冷凍日期及失溫狀況優先，已冷凍庫存不因重新裝袋而重算日期。[FDA嬰幼兒食品保存表](https://www.fda.gov/media/83740/download)

標籤至少填：食材、完整成分、過敏原、製作時間、冷凍時間、每格體積、格數、試味／一般用途、家庭使用期限。取出時另記解凍完成時間；每週頁面的日期是預定值，改期製作時要重填標籤。

## 解凍、復熱與吃剩

前晚只把隔日所需份數移入冷藏解凍；若用微波解凍，接著立即處理供餐。勿室溫解凍。解凍後24小時內使用；復熱至中心全部熱透，再攪拌降至可入口溫度，微波尤其要攪勻防熱點。已煮熟食物只復熱一次，吃過、碰口水或保存狀況不明的剩食丟棄。[NHS](https://www.nhs.uk/best-start-in-life/baby/weaning/safe-weaning/storing-and-reheating-food/)

**不將已解凍的熟食再冷凍**；生食解凍再煮熟的情境不同，本清單不據此替已解凍的副食品重新計時。[HSE：自製副食品](https://www2.hse.ie/babies-children/weaning-eating/nutrition-baby/homemade-food/)

可用溫度計核對設備與食物；清單中的「預定前晚解凍」不是只看日曆就可存滿兩天，應記實際時間。當餐未夠吃時另取未接觸口水的新份，按相同程序處理，不來回加熱整袋。
