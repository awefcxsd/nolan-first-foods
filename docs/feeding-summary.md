# Nolan 副食品 summary：食量、質地、調味與過敏原

查核日期：2026-10-29。[每日菜單](../plans/README.md) · [食材overview](../plans/overview.md) · [每週備餐](../prep/README.md)

這份表用來理解進程。Nolan滿六個月為2026-11-22；開始與進階仍看坐姿、頭頸控制、吞嚥與實際進食能力。目前沒有體重、生長曲線、奶量與每日實吃紀錄，因此不能據此開出個人每日必吃量。六個月前的提前試吃仍按原計畫的個別確認條件。

## 1. Volume-wise：每天的量怎麼增加

**先增加能舒服吃下的每餐量，再逐步建立餐次；不用每天或每逢生日固定加量。** 來源支持初期從少量起步，逐漸走向較完整餐量，沒有六、七、八、九個月人人相同的mL配額。原表15–30mL是起始提供量，不是長期一餐的上限。[CDC：少量起步](https://www.cdc.gov/infant-toddler-nutrition/foods-and-drinks/how-much-and-how-often-to-feed.html)

### 家庭可以怎麼走：備餐量算例

**下表60、90mL是示範逐步增加的家庭算例，不是醫學月齡標準，也不是Nolan必須吃完的量。** 約半杯是後續餐量的粗略參考，按杯具為約120～125mL；兩樣食材合計，母乳／配方奶不包含在內。體積不是克數，不能把稀粥加水後的mL當營養增加。

| 月齡與日期 | 本計畫餐次 | 可以採用的進程／算例 | 算例中的每日副食品量，不含奶 |
| --- | --- | --- | --- |
| 6個月：11/22～12/21 | 每天兩餐 | 初期每餐先提供15～30mL，仍餓就續添；熟悉後按實吃量增加 | 若兩餐各15～30mL，合計30～60mL；續添量另計，不限制在此範圍 |
| 7個月：12/22～1/21 | 從兩餐逐步到三餐，第三欄是候選 | 假設已舒服吃到60mL／餐，先穩定兩餐，再給第三餐少量嘗試 | 兩餐各60mL＝120mL；另加第三餐15～30mL，則約135～150mL；三餐各60mL則180mL |
| 8個月：1/22～2/21 | 逐漸穩定三餐 | 假設每餐從60增至90mL，再視食慾往約半杯發展 | 三餐各90mL＝270mL；若三餐都約半杯則約360～375mL，並非達標線 |
| 9個月：2/22～3/21 | 三個主要餐次 | 可用約半杯作備餐參考，依飢餓與飽足調整，不因月齡強迫跳量 | 三餐各約120～125mL時為約360～375mL；實際可多可少 |
| 10～11個月：3/22～5/21 | 三餐與奶類並行 | 著重營養密度、餐桌食物與自主進食，不要求每月再加固定mL | 依實吃與生長調整，沒有本計畫可核定的個人固定總量 |

UNICEF提供6～8及9～11個月從軟食逐步增加、約半杯的概念；NHS則以7～9個月逐步三餐、10～12個月三餐與奶類並行描述。這些是一般指引，不能相乘後就變成個人配額。不同來源對餐次與點心有差別，本家庭保留六月齡兩餐、後續三個主要餐次。[UNICEF：6～12個月](https://www.unicef.org/lac/en/parenting-lac/food-nutrition/feeding-baby-6-12-months)、[NHS：7～9個月](https://www.nhs.uk/best-start-in-life/baby/weaning/what-to-feed-your-baby/7-to-9-months/)、[NHS：10～12個月](https://www.nhs.uk/best-start-in-life/baby/weaning/what-to-feed-your-baby/10-to-12-months/)

實際增加的方法：吃完還主動張嘴、伸手要食物，就續添同餐食材；閉嘴、轉頭、推開就停。連續幾餐都需要續添，下次可多備一些；拒吃一天不等於要把下餐加倍。奶類持續提供，不按副食品mL一比一減奶。每天安排含鐵食物與多樣食物，不能只增加粥水。

冷凍的10mL格是庫存工具。食量增加後，要放大每批製作量與取用格數，不能把兩格20mL當成後期一整餐；新過敏原引入量也不能套用整餐算例。每餐仍最多兩樣，續添相同兩樣即可。

## 2. Texture-wise：泥→顆粒→軟固體

**不用等長牙或滿九個月才開始顆粒；具能力後，約六至七個月就可逐步練習。** 「固體」指可壓爛的軟食，不代表硬塊、生蘋果、整顆葡萄或堅果。

| 階段 | 質地進程 | 家庭準備例子 | 何時往下一步 |
| --- | --- | --- | --- |
| 約6個月起步 | 濃稠細泥、滑順軟食；不是只喝湯水 | 稠燕麥糊、細磨肉泥、蔬菜泥 | 能穩定坐好、控制頭頸，能把食物在口中移動與吞下 |
| 約6～7個月、有能力時 | 叉壓泥，逐步保留柔軟小顆粒 | 壓爛南瓜、熟蛋碎、壓碎豆腐 | 能處理目前軟度，不持續嗆咳、痛苦或明顯吞嚥困難 |
| 約7～8個月 | 更多軟顆粒、細碎食，搭配適合抓握的軟手指食物 | 充分煮軟的蔬菜條、柔軟短麵，形狀依抓握能力處理 | 能咬壓、移動食物並吞嚥，再逐步增加質地變化 |
| 約9個月 | 軟碎、細切與依捏取能力準備的軟食 | 細碎熟肉、去刺魚、軟蔬菜；不給大塊韌肉 | 能安全處理現有質地，再擴充，成人全程近距離看顧 |
| 約10～11個月 | 逐漸適應無額外鹽糖的家庭軟食 | 家常食材煮軟、去骨去籽、按能力切製 | 持續練習自主進食，不因菜名有「泥」就一直用完全細泥 |

這是練習方向，不是生日當天強制升級的時間表。NHS明確建議約六至七個月開始提供顆粒質地，10～12個月已有多種壓泥、碎食與手指食物；若反覆嗆咳或長期只能處理細泥，應請兒科／餵食專業人員評估，而非只延後月份。[NHS：起步質地](https://www.nhs.uk/best-start-in-life/baby/weaning/what-to-feed-your-baby/from-around-6-months/)、[NHS：後期質地](https://www.nhs.uk/best-start-in-life/baby/weaning/what-to-feed-your-baby/10-to-12-months/)

原菜單中的「肉泥／菜泥」應視能力改成壓泥或軟碎；本摘要提供進程，不替寶寶自動判定能力。若改變冷凍格質地，先確認復熱後依然足夠軟。

## 3. Seasoning-wise：什麼時候調味

| 項目 | 時機與做法 |
| --- | --- |
| 鹽、醬油、鹹高湯、調味粉 | 一歲前不額外加；不用等到某個月齡就開始「訓練吃鹹」。一歲後也不需要刻意加鹽，持續低鹽。 |
| 糖、糖漿、甜飲 | 不需添加，食材本身味道已可提供變化；不靠加糖促進進食。 |
| 蜂蜜 | 未滿一歲不給，包括加入料理或加熱的蜂蜜；不是一般香料的替代品。 |
| 無鹽的純香草／溫和香料 | 開始副食品後、具準備度且已能吃基底食物時，可少量增加風味，沒有必須等九個月或一歲的規定；避免刺激性辣味及含鹽糖混合調味料。 |
| 油脂 | 是營養的一部分，不是要等一歲才能用的鹹味調味品；本菜單已有酪梨、魚、堅果醬與全脂優格等來源。是否另外加油與量，需配合整體飲食，而非只為調味固定加。 |

NSW Health允許寶寶食物使用香草與香料，但不加鹽、鹹調味料、蜂蜜或糖。[NSW Health](https://www.health.nsw.gov.au/heal/child/menu/Pages/food-babies.aspx)

本家庭還有「每餐兩樣食材」限制：如果加油、香草或香料，就算額外一樣，不能在原本兩樣後默默加入；要替換同餐一項或另行調整規則。目前尚未把調味品加入自動菜單，本摘要不改動100種食材數量。

### 比一般小朋友多還是少？

**以指南的涵蓋度看，這份計畫已包含常見主要類別；以「台灣同齡平均吃過幾種／幾克」看，不能可靠地判定高於或低於平均。** 沒有可直接對照本表9類定義、月齡及實際攝取量的同一套平均值，也沒有Nolan的實吃量。

找到一篇台灣長庚小兒科團隊2017年出生世代研究：12個月時，有／無IgE致敏的兩組平均接觸項目為3.2與3.7。但研究只問六個項目，把水果算一項、蛋黃與蛋白拆開，與本計畫9類定義不同；又是觀察性研究，IgE致敏不等於臨床食物過敏。因此不能用「我們9、別人約3～4」宣稱比較好，也不能推論越多越能防過敏。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/29040259/)

### 為什麼要引入，是否應該增加？

主要目的：建立多樣飲食、不要不必要地延後常見食物，並把能耐受的食物持續納入日常。較明確的早期引入預防證據集中於**蛋與花生**；其他類別也建議在第一年逐步引入、優先家庭平常會吃的食物，但不能宣稱每增加一種都同等降低過敏風險。2026 ASCIA將其他類別引入的證據確定性列為很低。[ASCIA 2026建議2～5](https://allergy.org.au/hp/papers/infant-feeding-and-allergy-prevention/)

**本計畫更值得優先做的是確實引入並持續複習，而非為了數量把所有過敏食物趕著試完。** 若家裡常吃核桃或其他堅果、不同魚類，可考慮把它們的候選優先度往前調，取代較少吃的候選；每項仍分開少量引入，安全形式與後續複習一起規劃。目前未替它們新增首次日期。

ASCIA 2026建議已引入且無反應的常見過敏原至少每週持續提供；這個頻率屬專家共識，並非有證據證明一週兩次一定比一次更好。本計畫蛋與花生每週兩次、其他每週一次提醒，與此方向一致；份量仍需個別化，沒有所有過敏原共用的mL劑量。[ASCIA建議9～11](https://allergy.org.au/hp/papers/infant-feeding-and-allergy-prevention/)

一次餐點只新增一種過敏原，使用適合能力的食用形式，不塗在皮膚測試。若已有過敏、嚴重濕疹或疑似反應，先個別評估，不照排程自行挑戰；呼吸困難、舌喉腫脹或意識改變立即求救。

## 這份summary對原計畫的補充

- 15～30mL與10mL冷凍格是起步／庫存工具，後期依實吃增加，並非整個一歲前都只吃兩小格。
- 月齡提供練習方向，質地按能力進展；不能把「泥」字一路照做至一歲。
- 香草與油脂並非一定要等一歲，但在本家庭規則中要算食材，不能偷加第三樣。
- 本期已排9類主要過敏原，卻尚無實吃證明；100種與14項標記都不是實際試過數量。

本摘要沒有修改每日試新日期、餐次或備餐格數，也沒有自動宣告耐受。需放大備餐量時，依最近實吃紀錄調整庫存表；若要改試新優先度，再同步重產每日表與備餐表。
