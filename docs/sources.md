# 參考資料

查核日期：2026-10-29。以下支持一般原則；具體食材順序、每日菜色與日期是本專案為家庭安排的草稿，不是來源推薦的個人療程。

台灣來源詳見 [醫師與醫院資料比較](taiwan-recommendations.md)。其中有署名小兒科醫師的食物類別建議，但本次未找到標準的「一歲前必吃100種」醫師清單；本專案100種為家庭候選庫，不是醫師背書的名單。
